# One Emoji, One Dream Vacation

**Winning entry: 🌅** — a sunrise over the sea, the first sunrise in a new place.

Run it:

```bash
node main.ts
```

Then check `/output/entry.txt` — it should contain exactly one emoji, no trailing newline.

> The entry is chosen by a blind pairwise judge: one emoji, one dream vacation, no leaderboard.
